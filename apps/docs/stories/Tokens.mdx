# Tokens

Every value in Creance comes from `creance-tokens`. The package ships two things:

- `creance-tokens/tokens.css`: CSS custom properties prefixed `--cr-`, with light and dark themes.
- A typed JS export: `tokens` (the `var(--cr-…)` references) and `values` (the resolved light values).

```css
@import 'creance-tokens/tokens.css';
```

The theme follows the operating system by default. Set `data-theme="light"` or `data-theme="dark"` on `<html>` to force one. Use the **Theme** button in the toolbar to switch this page.

Tokens come in two tiers. **Primitives** (`--cr-blue-600`) are the raw palette and scales. **Semantic** tokens (`--cr-color-bg-surface`, `--cr-color-status-running-fg`) say what a value is for, and change between themes. Components use only semantic colour tokens.

## Liquid Glass

Creance follows Apple's [Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass) model: glass is **a functional layer for controls and navigation that floats above content**, and content itself stays on quiet, solid surfaces. In the kit:

- **Glass:** buttons, tooltips, the floating run header, the diff review toolbar, the inbox drawer. Use the public `.cr-glass` class (`data-glass="clear"` for the clearer variant) for your own controls, sparingly.
- **Solid (`.cr-surface`):** approval and tool call cards, diff hunks, inbox items, the timeline, the handoff banner.

The material has three layers: a tinted fill with backdrop blur and saturation; **refraction**, where content behind bends near the rounded edges like a lens (an SVG displacement filter sized to each element; Chromium only, other browsers get the rest); and a **specular rim** that catches light on the edges. Tinted glass (primary, danger) uses a deep, translucent fill so white text stays above 4.5:1. Controls swell and brighten when pressed, and content scrolling under the run header gets Apple's scroll edge effect.

**Known limit.** Apple's glass samples the content beneath it and flips between light and dark appearances to stay legible. CSS can't read the backdrop's colours, so Creance's glass can't adapt: over very bright or busy content, text on clear glass can fall below 4.5:1 (see **Atoms / Button / Over Content**). Keep glass controls over the canvas or calm content, which is where the contrast tests check them.

One switch makes all of it solid, with no blur or refraction:

- `prefers-reduced-transparency: reduce` (the macOS and iOS "Reduce transparency" setting)
- `prefers-contrast: more`
- `data-transparency="reduce"` on `<html>`, for an in-app setting

Use the **Surfaces** toolbar button to see the solid version. Text contrast on glass is tested in both themes (with the blur and lens off, which axe can't measure through).

## Motion

`--cr-motion-duration-fast`, `-base` and `-slow` are 120, 200 and 320ms. They drop to `0ms` when the user sets `prefers-reduced-motion: reduce`, so components that animate through these tokens respect it automatically.
