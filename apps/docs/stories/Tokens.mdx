# Tokens

Every value in Creance comes from `creance-tokens`. The package ships two things:

- `creance-tokens/tokens.css`: CSS custom properties prefixed `--cr-`, with light and dark themes.
- A typed JS export: `tokens` (the `var(--cr-…)` references) and `values` (the resolved light values).

```css
@import 'creance-tokens/tokens.css';
```

The theme follows the operating system by default. Set `data-theme="light"` or `data-theme="dark"` on `<html>` to force one. Use the **Theme** button in the toolbar to switch this page.

Tokens come in two tiers. **Primitives** (`--cr-blue-600`) are the raw palette and scales. **Semantic** tokens (`--cr-color-bg-surface`, `--cr-color-status-running-fg`) say what a value is for, and change between themes. Components use only semantic colour tokens.

## Sky and night glass

Creance's look comes from its name. A *creance* is the line a falconer keeps on a bird in flight, so the kit is drawn as a sky: **dusk** (the dark theme) and **dawn** (the light theme), with a soft violet glow on the horizon (`--cr-gradient-canvas`, `--cr-gradient-horizon`). Agents fly in it on lines back to you; see **Organisms / FleetSky**.

- **Aurora** (`--cr-color-accent-*`, `--cr-color-tether-taut`) is the one bright colour, kept for "needs you": the taut line, the request edge, the primary action. Text stays in the ink colours; colour marks state, it doesn't tint copy.
- **Moonlight** is running, **sage** is done, **coral** is failed, **lilac** is blocked and medium risk.
- **Type**: Instrument Serif for titles, Inter Tight for the interface, JetBrains Mono for commands. Load them from Google Fonts or self-host; the tokens fall back to system fonts.
- **Night glass** (`.cr-glass`, `.cr-surface`): translucent panels with a backdrop blur so the sky shows through. Under `prefers-reduced-transparency: reduce`, `prefers-contrast: more`, or `data-transparency="reduce"` on `<html>`, they turn solid. Use the **Surfaces** toolbar button to see it.

## Motion

`--cr-motion-duration-fast`, `-base` and `-slow` are 120, 200 and 320ms. They drop to `0ms` when the user sets `prefers-reduced-motion: reduce`, so components that animate through these tokens respect it automatically.
