# Tokens

Every value in Creance comes from `creance-tokens`. The package ships two things:

- `creance-tokens/tokens.css`: CSS custom properties prefixed `--cr-`, with light and dark themes.
- A typed JS export: `tokens` (the `var(--cr-…)` references) and `values` (the resolved light values).

```css
@import 'creance-tokens/tokens.css';
```

The theme follows the operating system by default. Set `data-theme="light"` or `data-theme="dark"` on `<html>` to force one. Use the **Theme** button in the toolbar to switch this page.

Tokens come in two tiers. **Primitives** (`--cr-blue-600`) are the raw palette and scales. **Semantic** tokens (`--cr-color-bg-surface`, `--cr-color-status-running-fg`) say what a value is for, and change between themes. Components use only semantic colour tokens.

## Sky and glass, almost no colour

Creance's look comes from its name: a *creance* is the line a falconer keeps on a bird in flight, so the kit is drawn as a sky, a slate night sky in the dark theme and a pale grey one in the light theme, where agents fly on lines back to you (see **Organisms / FleetSky**).

- **Neutral slate** does the work. Emphasis is contrast, not hue: "needs you" is a solid white pill in the dark theme (ink in the light theme), the taut line is bright, the primary button is solid.
- **Red** is the only colour: failures, high risk, Deny, removed diff lines.
- Statuses are told apart by icon and word first.
- **Type:** Instrument Serif for titles, Inter Tight for the interface, JetBrains Mono for commands, with system fallbacks.
- **Glass** (`.cr-glass`, `.cr-surface`): frosted, translucent panels so the sky shows through. They turn solid under `prefers-reduced-transparency: reduce`, `prefers-contrast: more`, or `data-transparency="reduce"` on `<html>`; the **Surfaces** toolbar button shows that.

## Motion

`--cr-motion-duration-fast`, `-base` and `-slow` are 120, 200 and 320ms. They drop to `0ms` when the user sets `prefers-reduced-motion: reduce`, so components that animate through these tokens respect it automatically.
