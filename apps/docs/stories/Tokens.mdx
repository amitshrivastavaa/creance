# Tokens

Every value in Creance comes from `creance-tokens`. The package ships two things:

- `creance-tokens/tokens.css`: CSS custom properties prefixed `--cr-`, with light and dark themes.
- A typed JS export: `tokens` (the `var(--cr-…)` references) and `values` (the resolved light values).

```css
@import 'creance-tokens/tokens.css';
```

The theme follows the operating system by default. Set `data-theme="light"` or `data-theme="dark"` on `<html>` to force one. Use the **Theme** button in the toolbar to switch this page.

Tokens come in two tiers. **Primitives** (`--cr-blue-600`) are the raw palette and scales. **Semantic** tokens (`--cr-color-bg-surface`, `--cr-color-status-running-fg`) say what a value is for, and change between themes. Components use only semantic colour tokens.

## Glass, grey and one blue

Frosted surfaces over a soft, blurred backdrop. Agents still fly on lines back to you in the sky (see **Organisms / FleetSky**): a *creance* is the line a falconer keeps on a bird in flight.

- **Neutral greys** carry the interface. Statuses are told apart by icon and word first.
- **Blue** is for the one action that answers a request, such as Allow once.
- **Ink** marks what needs you and what is selected: solid near-black in the light theme, off-white in the dark theme.
- **Red** is only for failure and refusal: failed runs, high risk, Deny, removed diff lines.
- **Type:** the system face (SF Pro on Apple devices, Inter elsewhere), bold and tightly tracked for titles; SF Mono or JetBrains Mono for commands.
- **Glass layers**, public classes apps can use too:
  - `.cr-window` frames a screen: the most translucent, with the strongest blur.
  - `.cr-surface` is a tile inside a window: cards, rows, panels.
  - `.cr-glass` is a sheet that floats above: requests, bars, drawers.
  - `.cr-popover` holds menus and tooltips, nearly opaque so text stays crisp.
- **Solid mode:** every layer turns opaque with no blur under `prefers-reduced-transparency: reduce`, `prefers-contrast: more`, or `data-transparency="reduce"` on `<html>`. The **Surfaces** toolbar button shows it.

## Motion

`--cr-motion-duration-fast`, `-base` and `-slow` are 120, 200 and 320ms. They drop to `0ms` when the user sets `prefers-reduced-motion: reduce`, so components that animate through these tokens respect it automatically.
