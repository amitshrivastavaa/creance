# FleetSky

Your agents as birds in a sky, each on a line back to you. A slack line is an agent flying on its own. A taut, glowing ember line is one that has come back because it needs you. The line is the *creance* the kit is named after.

<Canvas of={Stories.NeedsYou} />

## When to use

- The overview of several agents or runs: the first thing a person sees, answering "is anything waiting on me?" at a glance.
- As a hero or header band above a run or an inbox.

## When not to use

- **Detail.** The sky says *that* an agent needs you, not *what* it wants. Pair it with **NeedsYouInbox** or an **ApprovalPrompt**.
- **Many agents.** Past about eight birds the sky gets crowded. Group agents, or use NeedsYouInbox as the list.

## How status reads

| Status | Bird | Line |
|---|---|---|
| `running` | Flies its own loop | Slack and faint |
| `waiting` | Returns and hovers near you, larger | Taut, glowing ember |
| `blocked` | Hovers in place | Slack, lilac |
| `done` | Rests near you, wings folded | Short, sage |
| `failed` | Droops low | Dashed coral |

When an agent starts needing you, it visibly flies back: a status change is a movement, not just a colour swap.

## Accessibility

- **The canvas is decorative** (`aria-hidden`). Each agent also has a real name tag that follows its bird and says the status in words ("Deploy Fixer, needs you, wants to run npm install zod@3"). With `onSelect`, the tags are buttons, in a list, reachable by keyboard.
- **Announcements.** When an agent starts needing you, a polite live region says so ("Deploy Fixer needs you").
- **Motion.** Under `prefers-reduced-motion`, birds don't fly or flap and lines don't animate; every agent is drawn still at its position.
- **Not colour alone.** Status is carried by position, line shape (taut, dashed) and the tag text, as well as colour.
